# Changelog

## 1.1.0

- Shared ASCII, solid-cell, hybrid, tear and glitch presentation.
- Reusable parametric surfaces, smooth grid normals, wire grids and cached geometric text.
- Live canvas-to-glyph composition, glyph particles, JavaScript image deformation and an optional local raster-program interface.
- Shared resource ownership available to scene factories; layered diagnostic snapshots.
- Reused interleaved GPU buffers, per-draw light gain and correct normals under nonuniform transforms.
- Isolated delivery bundles: a project cannot import and publish another project's source accidentally.
- Manifest-driven cue, reverse-seek, ending, input and foreground renderer checks. Single-project checks, actionable mismatch diagnostics and neutral browser fixtures work in a clean installation.
- Expanded authoring API, delivery guidance and regression tests. Schema 1 / engine 1.0.0 projects remain supported; new projects declare 1.1.0.

This distribution contains engine code and neutral diagnostics only. Artistic acceptance projects and their assets are excluded. Credits remain entirely optional under the unchanged MIT licence.
